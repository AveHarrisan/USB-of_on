# Изменения

## 1.2.1

- Работа в трее: крестик прячет окно, программа продолжает следить за устройствами. Открыть — щелчок по значку, закрыть — правой кнопкой по значку → «Закрыть приложение» и подтверждение.
- Настройки → «Показывать только подписанные устройства»: в списке остаются только устройства с именем, остальные (мышь, клавиатура, камера…) не мешают.
- Уведомление у трея, когда подключают флешку, токен или другое устройство (Настройки → «Уведомлять о подключении устройств», включено по умолчанию). Щелчок по уведомлению открывает программу и подсвечивает устройство; если у него ещё нет имени и оно скрыто фильтром подписанных — сразу открывается окно имени.
- Вторая копия не запускается: повторный запуск открывает окно уже работающей программы.
- Программа ставится в «Program Files», а не в «Program Files (x86)». Старая копия удаляется сама, имена и скрытые устройства сохраняются.
- В «О программе» — кнопка «Инструкция» с подробным руководством, ссылка на GitHub и кнопка «Папка с сохранениями».
- Настройки → «Запускать при входе в Windows»: программа открывается сама, без окна UAC. Можно запускать сразу в трей. При удалении программы автозапуск убирается.

## 1.2.0

- Простой вид: устройства карточками вместо таблицы. У каждой — значок по типу (токен, флешка, телефон, камера, звук, клавиатура), понятное название, состояние, переключатель «вкл/выкл» и меню «⋯»: дать имя, скрыть, копировать сведения.
- Простой вид открывается по умолчанию. Таблица со всеми сведениями — кнопка «Подробный вид», выбор запоминается.
- Названия без служебных слов Windows: «Kingston DataTraveler 3.0» вместо «Запоминающее устройство для USB».

## 1.1.0

- Установщик: ярлыки в «Пуске» и на рабочем столе, удаление через «Приложения» Windows. При удалении программа спросит, оставить ли сохранённые имена.
- Обновления: программа сама проверяет новые версии, показывает полосу «Вышла версия…» и кнопку «Обновить». Установщик скачивается, ставится и открывает программу снова, скачанный файл потом удаляется.
- Окно «О программе» и кнопка «Поддержать» на панели.
- Своя иконка.

## 1.0.0

- Список USB-устройств: состояние, название, что внутри, буква диска у флешек, производитель, VID:PID, серийный номер.
- Имена и заметки для устройств, скрытие лишних.
- Включение и выключение устройств.
