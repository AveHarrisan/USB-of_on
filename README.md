# USB-of_on

Программа для Windows: список USB-устройств, имена для них, скрытие лишних и программное включение/выключение.

Сделана под ПК, в который вставлено много токенов УКЭП/ЭЦП (Рутокен, JaCarta и т. п.): каждому можно дать имя организации и включать только нужный.

## Возможности

- Показывает все USB-устройства: подключённые сейчас и названные ранее, но сейчас вынутые.
- Для каждого: состояние, название, что внутри (например, «Kingston DataTraveler USB Device»), буква диска у флешек, производитель, VID:PID, серийный номер.
- **Имя и заметка** — двойной щелчок, F2 или кнопка «Имя…». Имя привязано к устройству, а не к порту: у токенов и флешек с серийным номером оно сохраняется при перестановке в другой разъём.
- **Скрыть** — убрать из списка ненужное (телефон, мышь и т. п.). Del или кнопка «Скрыть». Вернуть: включить «Показывать скрытые» → выделить → «Показать».
- **Выключить / Включить** — то же самое, что «Отключить устройство» в Диспетчере устройств. Выключенное устройство остаётся в разъёме, но Windows с ним не работает. Состояние сохраняется после перезагрузки. Можно выделить несколько устройств сразу.
- Список обновляется сам при подключении и отключении устройств.
- Поиск по имени, заметке, описанию, серийному номеру.

## Установка

Скачать `USB-of_on.exe` со страницы Releases (или из артефактов сборки в Actions) и запустить. Установка не нужна, нужен .NET Framework 4.8 — он уже есть в Windows 10 и 11.

Программа запрашивает права администратора: без них Windows не даёт выключать устройства.

## Где хранятся имена

`C:\ProgramData\USB-of_on\devices.json` — общий файл для всех пользователей ПК. Его можно перенести на другой компьютер, но имена там сработают только для тех же самых устройств.

## Ограничения

- Выключается устройство, а не питание разъёма: обычные USB-контроллеры не позволяют программно обесточить порт. Для токенов и флешек результат тот же — система их не видит.
- Хабы выключать программа не даёт: за ними могут быть клавиатура и мышь. При выключении клавиатуры или мыши будет предупреждение.
- Если устройство занято (открыт файл с флешки, КриптоПро держит токен), Windows может применить выключение только после перезагрузки — программа об этом скажет.
- Устройство без серийного номера Windows различает по разъёму: если переставить его в другой порт, оно появится как новое, и имя нужно будет дать заново.

## Сборка

```
dotnet build src/USBofon/USBofon.csproj -c Release
```

Результат: `src/USBofon/bin/Release/net48/USB-of_on.exe`. При пуше тега `v*` GitHub Actions собирает exe и выкладывает его в Releases.
